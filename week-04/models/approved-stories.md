# Approved User Stories

* **US-01:** As a Student, I want to view room availability so that I know where I can study.
* **US-02:** As a Student, I want to book a room so that I have a guaranteed study space.
* **US-03:** As a Student, I want to cancel my booking so that others can use the room.
* **US-04:** As an Administrator, I want to block a room so that maintenance can be performed.
* **US-05:** As an Administrator, I want to unblock a room so that it can be booked again.
* **US-06:** As an Administrator, I want to review usage so that I understand resource utilization.
